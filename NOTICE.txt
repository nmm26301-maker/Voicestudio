VoiceStudio Android offline preview, 2026-10-08

Original model: k2-fsa/OmniVoice, Han Zhu and coauthors, Xiaomi Corp. and collaborators, 2026.
https://huggingface.co/k2-fsa/OmniVoice
https://github.com/k2-fsa/OmniVoice
Original code Apache-2.0. Original pretrained model CC-BY-NC per official model card.
Model is converted and INT8-quantized by gluschenko; decoder and tokenizer from onnx-community/OmniVoice-Onnx. Original pretrained-weight terms remain applicable. This package does not relicense those weights.
https://huggingface.co/gluschenko/omnivoice-onnx
https://huggingface.co/onnx-community/OmniVoice-Onnx
Audio decoder: Higgs Audio V2 tokenizer, Boson AI, via the above ONNX conversion.
Java generation port follows the original diffusion generation algorithm; Unicode duration estimator port follows Han Zhu/Xiaomi Apache-2.0 source.
Android runtime: ONNX Runtime 1.30.0, Microsoft, MIT; third-party notices included in source third_party/.
See MODEL_PROVENANCE.json for downloaded file SHA-256 values and exact source URLs.

This is an experimental native Android port, not an official upstream Android distribution. All 646 languages and Android device behavior have not been validated.
