# 手机专用 · 无需电脑的免费云端试用

VoiceStudio 1.5.24 云端版提供 **官方公开的 ZeroGPU 浏览器试玩入口**。无需安装本地模型，不需拥有电脑、显卡、GPU 服务器或自建网关。这是 **从 App 打开浏览器，再把生成的 WAV 导入 App** 的工作流，**不是**经认证可无限使用的后台合成 API。

## 手机怎么用

1. 打开 VoiceStudio > 工具 > 音色，允许麦克风，录制 3–10 秒清晰且自己有权使用的声音。填写录音实际说出的文字（建议填写，某些模型需要），保存人物音色。
2. 在录音卡或人物音色详情点 **导出 WAV 到手机**，保存到“下载”等浏览器可访问的文件夹。
3. 回到 VoiceStudio > 创作，输入想朗读的新文字，可点 **复制创作页文字**。
4. 点 **✦ 免电脑免费试用**，任选平台：
   - Qwen3-TTS 官方：https://huggingface.co/spaces/Qwen/Qwen3-TTS
   - IndexTTS 2.5 演示：https://huggingface.co/spaces/IndexTeam/IndexTTS-2.5-Demo
5. 在浏览器选择 Voice Clone 功能，上传刚保存的 WAV。**参考文本填写录音实际说出的原文**，创作文本才填写你希望生成的新文字；不要把两个输入框混淆。生成后下载 WAV。
6. 返回 VoiceStudio 免费试玩弹窗，点 **从手机下载的 WAV 导入作品**，选文件。文件通过音频格式、长度和静音检查后进入作品页，标题会参考下载文件名。
7. 若免费网页限制单次文字长度，将原文按顺序分成几段分别生成，下载后把文件命名为 `01.wav`、`02.wav`、`03.wav` 等。回到免费试听舱点 **将多段免费 WAV 拼成一份长作品**，一次多选对应 WAV；App 按文件名中的数字顺序预览，核对后合并，统一采样率并校验每段声音。

## 费用保护

- 初次安装默认 **不允许任何应用内云端 API 合成请求**：Fish Audio、ElevenLabs、MiniMax、自己的网关及后台恢复任务均被保护。应用内“音色 / 设置”的费用保护卡片可主动解锁；解锁意味着可能消耗你平台额度或产生费用，不代表一定收费。
- 关闭费用保护后如再次开启，后台合成、续传和新提交均停止，直到明确重新允许。已生成作品和 WAV 不会因此删除。
- 免费网页演示不需要解锁 API；ZeroGPU 每日额度有限、需排队，可能需要登录或暂停服务。并不承诺一定有可用时段。
- 官方 ZeroGPU 用量细则：https://huggingface.co/docs/hub/spaces-zerogpu 。截至 2026 年 10 月，官方页面列出的 Free 用户每天包含 5 分钟 GPU 时间，实际额度、排队优先级与服务状态可能调整；这不是 5 分钟生成音频时长。
- **不要使用公开演示上传他人未经授权的音频、敏感录音或私人机密材料。** 文件会发送给被选的第三方平台，需遵守其存储、隐私与使用条款。
- 真实 API 直连 / 自建网关 / 四款开源模型 worker 可继续由懂部署的用户使用，但不是“无需电脑免费”路径。

## 当前边界

免费工作流支持通过浏览器生成并导入短文本音频，也能把下载的多个音频片段合并成一份作品。**这不是自动的超长文本 TTS**：每一段仍需要用户在网页独立生成并下载，是否提供导出功能由 Space 决定。合并限制为每次 2—24 段，每段最长 300 秒，合并后最多 30 分钟；输入总大小不超过 96 MiB。只有可解码的 WAV 才能合并，合并前会显示文件顺序；支持 1、2、10 等数字自然排序，也可使用 01、02 编号。合并期间可查看进度或取消，失败片段不会发布成作品。任意长文本的全自动分段、云端克隆和断点续传仍是 VoiceStudio API/网关模式的能力，需要真正的服务端。不要把公共 Space 当作没有限制的批量任务接口或保证商业使用。导入目前只支持 App 能验证的完整 PCM WAV，非 WAV 输出请在浏览器/正规转换工具另存 WAV；App 不做伪音频转码。

升级请使用 **原包名和原签名**，否则原有录音和作品无法被应用原位继承；不要卸载旧版后再试。
