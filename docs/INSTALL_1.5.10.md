# VoiceStudio 1.5.10

直接安装覆盖已交付的 1.5.1—1.5.9，不卸载。包名和原证书延续；原 com.voice.studio 的 1.5.0 仍是另一个安装身份。

音色 → GPU 加速接口：切换 ZeroGPU / Modal / Kaggle / 自定义平台。配置后回到创作生成。HF 自动分段，人物片段在同一连续任务内复用。REST 长文也会分段；Modal 每段计一次调用。

暂停/失败后点“继续”：已完成段复用；已有音频地址只重试下载。若原请求是否完成无法确认，会提示再重新提交该段；这可能再次消耗额度，完整段不会从头重做。工具 → 任务也提供同一恢复流程；批量恢复跳过需要重提确认的 GPU 任务。

手机验收：输入超过 180 字、含换行与表情的文本；检查结尾、各段人物音色；试断网、取消、恢复与作品导出。自动音色跨段可能不同；保存人物参考录音后主动勾选上传更适合长文。缓存占用空间，删除对应任务会一并清理。

文件、样本数和过短结果检查不能证明逐字正确。HF 有实际每日额度与排队，服务缓存重启/删除后可能需要新任务。Modal/Kaggle 尚未在用户账号运行，不宣称手机整体提速倍数。
