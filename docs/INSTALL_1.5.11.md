# VoiceStudio 1.5.11 安装与验收

安装签名正式 APK，可覆盖已交付的 com.voice.studio.preview / 1.5.1—1.5.10。名称为 VoiceStudio，versionCode 27。请直接覆盖安装，保留作品、模型和人物音色。原 com.voice.studio / 1.5.0 属于不同安装身份，不能覆盖。

## 手机上检查

1. 确认原有作品、音色、模型仍在，并试播一条旧作品。
2. HF 生成一段长文，观察“分段已保存”随完成分段变化；下载或合并期间应继续显示当前阶段，成功后才出现播放。
3. 下载中临时断网后恢复：允许最多两次下载重试；仍失败时点继续，已有分段会复用。排队连接中断若结果未知，需要确认后才能再次提交未完成段。
4. 点击取消，确认没有半段音频被写入作品；继续时检查末句仍在，并试听分段衔接。
5. 使用自己的参考音色时，注意参考文字与录音对应。自动音色在不同长文段落可能变化；本版未改变模型声音质量。

## 已完成与未完成的验证

通过宿主测试、构建、最终签名/ZIP/16 KiB 对齐及与 1.5.10 的升级身份检查。仅修改音频接收后校验和下载恢复，不据此承诺 GPU 排队或模型推理变快。未执行真机安装、真实麦克风或逐字语义验收。
