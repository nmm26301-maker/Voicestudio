# VoiceStudio 1.5.12 安装与验收

同签名正式 APK，versionCode 28，可覆盖已交付的 com.voice.studio.preview / 1.5.1—1.5.11。直接覆盖安装后，检查原有作品、音色和模型。原 com.voice.studio / 1.5.0 属于另一安装身份。

1. 本地合成同一段文字，试听开头、结尾、长文分段衔接，确认末句完整。
2. 选择自己的参考音色，再使用自动音色，检查响度和长文人物一致性。
3. 在本机解码音频阶段取消任务，再继续；检查不会将半段音频写入作品。
4. 已完成任务记录的 synthesisTiming 提供实际模型、解码及 PCM 写入时间。本版减少输出处理的数组分配，并未保证手机模型推理提速。

已通过主机纯 Java/原生自制 ONNX 图测试、构建、实际 APK 签名与升级身份检查。未执行真实权重语音质量或真机安装验收。

同版私有备份包含交付 APK、原有签名、密码/别名说明与哈希记录；私有 GitHub 备份凭据上传仍待指定目的地授权。
