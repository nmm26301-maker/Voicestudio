# VoiceStudio 1.5.13 安装与验收

同签名正式 APK，versionCode 29，覆盖已交付的 com.voice.studio.preview / 1.5.1—1.5.12。直接覆盖安装，检查原有作品、人物音色和模型。原 com.voice.studio / 1.5.0 是不同安装身份。

1. 使用本机 OmniVoice 生成长文，完成若干段后暂停。
2. 在原任务中点击“继续此任务”，观察“复用已完成的本机推理”；重新创建任务拥有独立缓存。
3. 最终试听末句和分段衔接，确认作品完整。首次生成仍需模型推理，缓存恢复仍需音频解码和保存。
4. 选择参考音色重复测试，再测试自动音色。运行记录 synthesisTiming 的 reusedEncodingChunks 显示复用段数，modelRuns 显示实际主模型调用数。
5. 删除任务后，其私有分段缓存一并移除；不要手工在保留旧大小和修改时间的情况下替换大型权重并复用旧任务缓存。

通过构建、宿主回归、原生自制 ONNX 图恢复与 WAV 一致性测试、最终签名和覆盖升级身份检查。未进行手机安装或真实模型语义验收。
