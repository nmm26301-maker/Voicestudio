# VoiceStudio 1.5.14 安装与验收

versionCode 30，同签名覆盖已交付的 com.voice.studio.preview / 1.5.1—1.5.13。直接覆盖安装后检查原作品、音色与模型。原 com.voice.studio / 1.5.0 不能覆盖。

1. 本地长文在解码完成几段后暂停，继续原任务，观察“复用已完成的本机音频”。
2. 试听开头、结尾、分段衔接和响度；完整作品保存前仍显示处理状态。
3. 自动音色和自己的参考音色都测试一次。新建任务使用独立缓存。
4. synthesisTiming 的 reusedDecodedChunks 是音频复用段数；decoderRuns 是实际解码调用。全缓存恢复仍需读取、校验和合并，不等于瞬间完成。
5. 每输出目录音频缓存最多 64 MiB，达到上限正常生成；任务删除同时清理私有缓存。

通过宿主回归、自制原生 ONNX 图恢复及输出字节对比、构建、实际 APK 签名/版本/升级身份检查。未进行真机安装与真实权重语音质量验收。
