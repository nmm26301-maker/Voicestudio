# VoiceStudio 1.5.15 安装与验收

versionCode 31，同签名覆盖已交付的 com.voice.studio.preview / 1.5.1—1.5.14。直接覆盖安装，检查原作品、音色与模型。原 com.voice.studio / 1.5.0 是另一安装身份。

1. 生成本地长文，首段解码完成后观察“试听已完成片段”。按钮出现时间由模型调度决定，参考音色批处理中可能较晚。
2. 点击试听，检查声音、读音和响度；关闭播放器继续等待，或点“取消剩余生成”。
3. 完成后播放完整作品，检查末句和分段衔接。片段不会被列为完整作品。
4. 选择明确配置的 GPU 接口生成长文，已有完成 WAV 分段时检查试听入口。Fish 与手机 TTS 没有这一片段入口。
5. 试听时切后台、拔耳机、旋转页面；确认播放停止/窗口释放。暂停或失败后仍可听已有有效片段，继续任务保留缓存行为。

通过构建、宿主回归、自制原生 ONNX 图首段就绪与完整音频字节对比、最终签名/升级身份检查。未实测设备播放/生命周期、真实权重读音或手机速度。
