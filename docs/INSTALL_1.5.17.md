# VoiceStudio 1.5.17 安装与验收

versionCode 33，同签名覆盖已交付 com.voice.studio.preview / 1.5.1—1.5.16。直接覆盖安装后检查原作品、音色和模型。原 com.voice.studio / 1.5.0 是另一安装身份。

1. 音色 → 选择 / 删除已保存音色 → 我的声音：核对参考片段秒数与参考文字。文字应仅包含所选片段实际说出的内容。
2. 点击“修正文字并重建音色”，修正原片段文字或留空重新识别，创建“修正版”；试听原声核对，完成后选择新音色再生成。原音色与原声不会删除。
3. 用一段正常 3—10 秒录音配上大量不对应文字创建音色，应得到具体错误，保留录音；旧的异常音色也应在推理前失败。
4. 重新生成截图全文并导出 WAV。检查完整读到最后、听清每个词；短结果不能因文件有效而被保存成功。提供实际 WAV 与输入全文才能继续定位错读，截图不足以判定声音质量。
5. 语速先用 1.0×，保留现有步数选择。32 步增加运算，真实模型测试也有错读，不保证解决清晰度。

已完成宿主回归、真实模型时长/参考检查、Android 构建与同签名升级验证；真机 UI 与用户音色的逐字听辨尚未验收。不能据此声称手机推理已加速或声音质量已修复。
