# VoiceStudio 1.5.18

同签名覆盖 com.voice.studio.preview / 1.5.1—1.5.17，versionCode 34。覆盖安装后保留作品、模型和音色；原 com.voice.studio / 1.5.0 属另一安装身份。

1. 首页保持“我的声音”，输入“你好”或与录音不同的新文字生成。旧参考时长检查已移除，录音与新文字不需要相同；有原声和识别模型时会自动校正异常录音文字。不能保证识别或长句逐字准确。
2. 打开此前的人物提取结果 → 按人物数量重新分组 → 填 3。使用原音轨重新聚类并提取，新结果最多 3 组（没有足够可区分证据时可能更少）；原结果保留。
3. 新视频提取也可直接填写人数。人数未知填 0；无需通过调高阈值控制人数。试听后命名和创建人物音色。
4. 新分组结果可直接校对字幕编号并再次提取，无需重新导入视频。

真实控制参考的本地短句生成/ASR核对、算法与宿主回归、Android 构建及同签名升级检查通过；未完成用户参考音色、原视频身份、真机播放和速度验收。

完整签名备份包含该次 APK、既有密钥和密码说明。私有 GitHub 密钥上传仍待明确目的地授权；没有创建新签名。
