# VoiceStudio 1.5.19

直接覆盖更新已交付的 1.5.1—1.5.18；安装身份和签名保持一致，versionCode 35。不要卸载旧应用。作品、模型和音色使用原数据目录；数据保留仍需手机验收。原 com.voice.studio / 1.5.0 是另一安装身份。

1. 使用“我的声音”生成与录音内容不同的文字。安装 Whisper 后，未核对的旧音色首次使用会检查录音内容，核对成功后再次生成不重复识别。
2. 新建音色时可直接录音并留空参考文字自动识别；手填文字应对应录音片段。明显内容差异会修正，小幅识别差异保留手动校对。没有识别模型时，手填文字仍可创建音色。
3. 32 步一至两个汉字的克隆使用至少 2 秒模型预算（语速 1），不追加静音；其他生成方式不变。32 步长句与 16 步短句有真实控制样本；详细识别差异见验证记录。不能保证任意录音和任意文本逐字准确。8 步仍是实验选择。
4. 本地静音片段会停止保存，不会显示为成功作品。完整作品仍在“作品”页；首段试听仅用于提前听取，不表示整篇已完成。
5. 视频人物提取继续支持人数 3 和原音轨重新分组，原结果保留；本次未修改人物聚类算法。

已准备的 GitHub 加密备份仍待明确授权 Zizai 私有目的地后提交，原签名及密码说明在 ZIP 内。用单独保留的 VoiceStudio-1.5.19-Backup-Recovery-Key.json 和 tools/restore_encrypted_backup.py 恢复；也可以直接使用交付的未加密私有备份 ZIP。没有创建新应用签名。
