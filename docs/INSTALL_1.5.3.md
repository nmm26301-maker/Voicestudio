# VoiceStudio 1.5.3 安装与人物音色验收

可直接更新已交付的 1.5.1 测试版或 1.5.2 正式版；包名与证书保持一致，versionCode 升为 19。无需卸载。实际安装与数据保留尚待手机验证。

## 直接录音创建人物音色

1. 工具 → 音色 → 人物音色实验室。点击“开始录音”，首次授权麦克风；清晰录制单人声音至少 3 秒，最多 10 秒自动停止。
2. 页面显示真实音量和计时。点击“结束录音”，再“试听录音”；不足 3 秒时保存按钮不可用。
3. 填写人物名称及说出的文字，点击“保存为人物音色”。文字留空需 Whisper；创建需克隆模型，合成另需基础 OmniVoice 模型。
4. 任务完成后在“选择 / 删除已保存音色”中选择人物声音，返回创作生成。可试听保存音色的参考原声。
5. 验证拒绝授权、短录音、重新录音、录制时切页/返回/锁屏、旋转后草稿保留、耳机断开和其他录音占用。确认提交后重录不会改变已排队音色。

## 视频提取人物声音

1. 安装 Whisper 与说话人分组模型。音色页点击“从视频提取人物声音”，选择有对白的短视频并开始任务。
2. 完成后点击“打开人物提取结果”，逐组试听，对应人物命名；每组可导出全部对白 WAV，并试听最长 10 秒的参考片段。
3. 选“命名并创建人物音色”。没有识别模型时填写参考片段文字；不足 3 秒的声音可导出，但需补录后创建音色。
4. 分组有误、字幕含多个说话人或短片段未分组时，校对字幕、拆分/合并时间段、修改人物编号。然后点击人物结果页“按最新校对结果重新提取”；普通转写任务也可从转写与字幕 → “提取每位人物的声音”进入。
5. 测单人、两人交替对白、长于一分钟、背景音乐、无音轨视频、取消与继续；核对人物导出不串音、不丢尾部。重叠对白暂不支持逐人分离，画面人物身份需自己核对。

## 每次发布备份

已按本轮要求私下保存新 APK 与完整发布备份（含相同签名密钥）。今后每次交付保留独立版本备份，不覆盖旧版、不生成新签名，不公开私钥。

`tools/backup_release.py` 核对 APK 签名与现有密钥后将完整 APK、PKCS12 密钥及哈希记录写入私有 ZIP。还原密钥到 `signing/voicestudio-preview.p12`，使用 `VOICE_STANDALONE=1 bash tools/build.sh` 构建。原 1.5.0 仍是独立安装分支。
