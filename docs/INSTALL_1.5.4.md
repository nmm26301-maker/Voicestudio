# VoiceStudio 1.5.4 安装与生成速度

可直接更新本次此前交付的 1.5.1 测试版、1.5.2 / 1.5.3 正式版。包名与签名不变，versionCode 升为 20，无需卸载。手机实际安装与数据保留尚待验证；不能覆盖原 `com.voice.studio` 的 1.5.0。

## 使用极速模式

1. 音色页选择 OmniVoice 本地引擎，确保合成模型已安装。
2. 创作 → 生成速度 → 选择生成速度 → 极速 · 8 步（实验）。也可在工具 → 音色 → 设置自动音色与采样参数中选择。
3. 使用相同短文本、音色和随机种子，分别试听 8、16、32 步。检查漏字、发音、噪声、断句及音色相似度，按试听结果选择。16 步仍为默认值。
4. 已排队的任务使用提交时的配置；切换速度后重新提交才能应用新模式。语速控制说话节奏，不代替生成速度选择。

8 步相对 16 步减少模型运算次数；模型加载、分词和解码仍需时间，因此总耗时不会必然减半。长文本仍分段合成，自动音色沿用首段锚点。

## 手机验收与比较

- 安装前记录已有作品、模型及人物音色数量，覆盖安装后核对并试听，不要卸载清除数据。
- 同一手机、文本、音色、种子、模型版本和温度环境分别提交 8 / 16 / 32 步，重复测量；记录总耗时、语音质量和发热。任务保留 `synthesisTiming` 的分项耗时与实际模型运行次数。
- 验证短句、长文本、自动音色、录音创建的参考音色、批量、有声书、暂停/取消/继续和失败重试。旧任务的参数应保持原值。
- 人物录音及视频提取的详细验收继续按 [1.5.3 人物音色验收](INSTALL_1.5.3.md) 执行。

每次交付的安装包和同一签名文件均单独私下备份。保留各版本备份，后续升级不得重新生成签名密钥。
