# VoiceStudio 1.5.5 安装与多核加速验收

沿用已交付 1.5.1—1.5.4 独立版本的包名和签名，versionCode 升为 21，可直接选择更新，无需卸载。实际覆盖安装与数据保留尚待手机验证；原 `com.voice.studio` 1.5.0 使用另一签名。

多核采样自动启用，不需要新设置。少量剩余位置保持单线程，较长片段最多使用 4 个线程；8/16/32 步选择、默认 16 步、随机种子和已排队参数保持原行为。

## 手机核对

1. 安装前记录模型、作品、参考音色和配置，覆盖更新后核对、试听；不要通过卸载清除数据。
2. 使用同一手机、模型、文本、音色、种子和步数比较 1.5.4 与 1.5.5，重复运行并记录总耗时、发热及声音。短句、长文、自动音色和录音创建的参考音色都要覆盖。
3. 测试暂停/取消/继续、失败后重试，以及批量、有声书、字幕配音；中止后不应继续出现后台采样任务。
4. 普通 TTS 的 `synthesisTiming` 记录模型/采样分项耗时、实际采样线程数和并行轮数。宿主基准的 52%—60% 仅是采样阶段结果，不能当作手机整体生成提速。

极速 8 步仍为实验模式，音质与克隆相似度需试听确认。此前人物录音及视频提取步骤继续按 [1.5.3 验收](INSTALL_1.5.3.md) 执行。

每次发布 ZIP 包含实际 APK、原有 `.p12`、密码/别名恢复说明及校验记录。GitHub 密钥备份仅能放入明确授权的私有仓库；公开源码不保存密钥或发布归档。
