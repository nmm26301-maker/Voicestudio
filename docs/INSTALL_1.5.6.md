# VoiceStudio 1.5.6 安装与加速验收

沿用此前交付的 1.5.1—1.5.5 独立版本包名与签名，versionCode 升为 22，直接更新即可，无需卸载。原 `com.voice.studio` 1.5.0 是另一安装身份。实际覆盖安装与数据保留尚待手机核对。

本轮优化自动应用：长文本减少合成/解码模型重载；能够明确解析输出元数据的模型从首轮起使用预分配缓冲区。未知/冲突元数据和半精度输出保留旧读取流程。默认 16 步、极速 8 步实验选项、32 步及已经排队的配置保留。

## 手机对照

1. 记录原有模型、作品、参考音色和设置，再覆盖安装，核对并试听。
2. 使用相同模型、文本、音色、种子和步数比较 1.5.5 与 1.5.6，覆盖短句和超过 32 段的长文本，重复记录总耗时、发热及声音。测试自动音色与页面录音创建的参考音色。
3. 测试生成中取消、暂停/继续、失败重试、批量、有声书和字幕配音。较大分组仍应按原顺序输出，取消后应关闭当前模型。
4. 普通 TTS 的 `synthesisTiming` 可检查 `backboneLoads` / `decoderLoads`、`prePinnedChunks`、`outputCopyBytes`、`outputShapeFallbacks`。未知形状时复制字节不为零是兼容回退，不代表任务失败。

80 段测试图的 6→2 次加载与首轮基准的 25%—54% 耗时减少，都不能换算成手机整体提速。2 MiB 左右仅是编码暂存上限，整个模型峰值内存需真机测量。8 步音质仍需试听确认。

人物录音及视频提取的功能步骤继续按 [1.5.3 验收](INSTALL_1.5.3.md) 执行。每次交付完整 ZIP 均包含实际 APK、原有密钥及密码/别名恢复说明；GitHub 的签名与密码备份仍等待具体私有仓库目的地的明确授权。
