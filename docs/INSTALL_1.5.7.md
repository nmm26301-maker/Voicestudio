# VoiceStudio 1.5.7 安装与加速验收

沿用此前交付的 1.5.1—1.5.6 独立版本包名与签名，versionCode 升为 23，直接更新即可，无需卸载。原 `com.voice.studio` 1.5.0 是另一安装身份。实际覆盖安装与数据保留尚待手机核对。

本轮优化自动应用：同帧数连续片段复用解码器输入，以及已观察到的 float32 音频输出缓冲区。帧数改变时重新准备；输出形状随内容改变时自动回退；半精度或超过 64 MiB 输出保留原读取方式。默认 16 步及排队配置继续保留。

## 手机对照

1. 记录模型、作品、参考音色和设置，再覆盖安装，核对并试听。
2. 使用相同模型、文本、音色、种子和步数比较 1.5.6 与 1.5.7，覆盖短句、连续多段、不同长度片段以及长文本；重复记录总耗时、发热及声音。测试自动音色与页面录音创建的参考音色。
3. 测试生成中取消、暂停/继续、失败重试、批量、有声书和字幕配音；中断后不应继续保存完成作品。
4. 普通 TTS 的 `synthesisTiming` 可检查 `decodedPinnedChunks`、`decoderOutputCopyBytes` 和 `decodeMillis`。单段或帧数持续改变时复用次数可能为零；兼容回退不表示任务失败。

诊断图张量路径的耗时减少 5.96%—46.38%，不能换算成手机整体提速。完整模型峰值内存、持续运行发热与真实音质需手机测量。

人物录音及视频提取步骤继续按 [1.5.3 验收](INSTALL_1.5.3.md) 执行。每次交付完整 ZIP 均包含实际 APK、原有密钥及密码/别名恢复说明。GitHub 的签名与密码备份仍等待具体私有仓库目的地的明确授权。
