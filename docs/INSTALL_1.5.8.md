# VoiceStudio 1.5.8 安装与验证

同签名更新 1.5.1—1.5.7 独立分支，包名仍为 `com.voice.studio.preview`，versionCode 24。无需卸载；模型、音色和作品使用原数据目录，实际保留情况仍需手机核对。

## 先检查短句与读字

1. 记录旧版的输入原文、音色、步数、种子、生成耗时和实际音频。确认使用的是 OmniVoice、手机语音还是 Fish。
2. 更新后使用同一录音参考和原文再生成，尤其检查短句是否读完。参考文字应为录音中实际说的话。
3. 对长句逐字试听结尾；不要仅依据任务完成、时长或 WAV 可播放判断正确。8 步仍为实验选项，读字不完整时需比较 32 步。
4. 对照手机发热和整体耗时。没有在真实手机上验证过本版速度；本机模型运行仍可能很慢。

## 使用加速接口

音色 → GPU 加速接口，填写自己已部署的服务地址、模型/服务器音色与密钥，再回到创作页。服务器默认单独请求 32 步。没有服务地址时，这项功能不能凭空提供 GPU；本机原有功能仍可使用。

部署方式与服务边界见 [加速接口说明](ACCELERATED_API.md)。普通创作明确选择接口才发送文字；原录音参考不自动上传，批量/有声书/字幕配音仍沿用本机流程。实际服务端速度、手机网络、认证、语义准确性与取消需另行验收。

本轮已修复参考短句时长的具体代码缺陷，**尚未把本地读字准确性标为通过**。请保留出现“一个字就结束”的原文与生成音频，以便继续定位真实故障。
