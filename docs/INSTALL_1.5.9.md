# VoiceStudio 1.5.9 安装

直接安装本次 APK 覆盖已交付的 1.5.1—1.5.8，不卸载；包名和签名沿用原有身份。原 com.voice.studio 的 1.5.0 签名仍不匹配，本 APK 与其并存。

打开音色 → GPU 加速接口，选择 Hugging Face → 配置并使用 ZeroGPU，默认官方地址可先留空 Token 尝试。回到创作输入完整文字生成。需人物音色时主动选择参考录音上传。Modal 按部署说明配置自己的账号服务；Kaggle 使用 Notebook 导出和 WAV 导入。申请、额度网站均可在页面直接打开。

手机验收：短句、跨行与多段中文分别试听完整结尾；检查首轮冷启动、额度不足提示、取消、恢复、人物音色和作品导出。HF 网络与额度受平台限制；本次 APK 的设备实测仍需用户手机完成。
